# Santosh Anime Hub — Hindi Dubbed Anime Watching Website (संतोष हिंदी एनीमे हब)

**Santosh Anime Hub** भारत का नंबर 1 आधुनिक और प्रीमियम हिंदी डब्ड एनीमे और मूवीज स्ट्रीमिंग प्लेटफॉर्म है। इसे **संतोष (Santosh)** द्वारा Next.js 15, TypeScript, Tailwind CSS और Prisma के साथ डिज़ाइन और विकसित किया गया है।

---

## 🌟 मुख्य विशेषताएं (Key Features by Santosh)

1. **प्रीमियम हिंदी डब्ड एनीमे लाइब्रेरी**:
   - Demon Slayer, Jujutsu Kaisen, Solo Leveling, One Piece, Attack on Titan, Naruto Shippuden और अन्य सुपरहिट सीरीज़।
   - Your Name, Suzume, Mugen Train जैसी ब्लॉकबस्टर हिंदी मूवीज।
2. **स्मार्ट फ़िल्टर एवं श्रेणियां**:
   - Action, Fantasy, Adventure, Movies, Series और मेरी वॉचलिस्ट (Watchlist) के लिए तुरंत एक-क्लिक फ़िल्टर।
3. **लाइव सर्च बार (Real-Time Search)**:
   - हिंदी एवं अंग्रेज़ी नाम, श्रेणी या कहानी के आधार पर तुरंत सर्च परिणाम।
4. **इंटरएक्टिव वीडियो प्लेयर मॉडल (Watch Episode Modal)**:
   - बिना किसी बफरिंग के एम्बेडेड प्लेयर सपोर्ट।
   - एपिसोड चयनकर्ता (Episode Selector - EP 1, EP 2...)
   - ऑडियो चयन: हिंदी डब्ड (Hindi Dub) / जापानी सबटाइटल (Japanese Sub)
5. ** Santosh VIP वॉचलिस्ट प्रबंधन**:
   - पसंदीदा एनीमे को अपनी वॉचलिस्ट में एक क्लिक में जोड़ें और काउंटर बैज देखें।
6. **रेस्पॉन्सिव एवं डार्क ग्लासमोर्फिज़्म UI/UX**:
   - मोबाइल, टैबलेट और डेस्कटॉप स्क्रीन के लिए आकर्षक डार्क थीम और 4K HD क्वालिटी बैज।

## 🚀 लोकल या Sandbox में कैसे चलाएं (Port 3000)

```bash
# 1. पैकेज इन्स्टॉल करें
npm install

# 2. डेवलपमेंट सर्वर शुरू करें (Port 3000)
npm run dev
```

सर्वर चालू होने के बाद आप अपने ब्राउज़र में `http://localhost:3000` (या Sandbox Live Preview URL) पर जा सकते हैं।
