Frequently asked questions

Does client-side mode really need no server?

Yes. In client-side mode, Okapi BM25 ranking, tokenization, and typo tolerance run inside the visitor's browser or Web Worker against a static JSON index. Hosted API keys on Team and Platform add server-side rate limiting and multi-origin search.

How do I embed it?

One script tag: plus a container div with data-search-embed. Full documentation is in the repository README.

Can I cancel anytime?

Yes. UPI AutoPay or monthly payment — cancel from the dashboard at any time with zero lock-in.

Is my search data private?

With client-side mode, search queries never leave the browser. With the hosted API gateway, keys are hashed using scrypt (N=16384, r=8, p=1) and verified in constant time.

What does Platform's autonomous agent mode do?

You define a recurring search objective — such as monitoring high-signal records every morning — and the agent executes on schedule, detects semantic drift or anomalies, and exports clean JSON/CSV digests.
