FAQ

Does it really need no server?

The search engine (BM25 ranking, indexing, fuzzy matching) runs in a Web Worker inside the visitor's browser. Your site just serves a static JSON index file. The only server-side piece is optional API key management for the Pro/Ultra tiers.

How do I embed it?

One script tag. <script src="https://santoshkumarvvv.github.io/embed.js"><script> plus a container div. Full docs in the README.

Can I cancel anytime?

Yes. UPI AutoPay or monthly card — cancel from the Razorpay dashboard, no questions asked. No lock-in.

Is my search data private?

With the free/client-side mode, search queries never leave the browser. No third party sees what your users search.

What does Ultra's agent mode do?

You write one instruction — like "every morning at 8am send me the top 3 data engineering jobs" — and the system runs it on schedule and delivers results without you re-searching. Up to 3 runs per day, 20 per week.
